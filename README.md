# Portofolio Argya Madha Putra

Struktur:
- `index.html` — halaman utama
- `css/style.css` — seluruh styling
- `js/script.js` — animasi dan interaksi
- `foto portofolio/` — letakkan semua foto yang dipakai HTML

## GitHub Pages
Pastikan nama file utama adalah `index.html`.
Upload juga folder `foto portofolio` dengan nama file dan huruf besar/kecil yang sama persis seperti yang dipanggil di HTML.
